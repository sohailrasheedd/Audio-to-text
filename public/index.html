💻 Desktop PC Local Engine Notice

Local CPU Mode is strictly designed for local Desktop/Laptop computers running the local Whisper executable and local Python server.

  • Mobile Devices (Phones/Tablets): Mobile browsers cannot execute local C++ binaries or local neural network models.
  • Online Vercel Website: Cloud servers cannot connect to your personal PC's local CPU hardware.
👉 Recommendation: Use Cloud Turbo API above for instant 1-2 second transcription on any phone, tablet, or web browser!
🔒 Data Flow & Privacy Guarantee

Where does your audio data go?

  • Direct Encrypted Stream: Your voice notes are transmitted securely via TLS/HTTPS directly to Groq Cloud Whisper LPU (or OpenAI) solely to convert audio into text.
  • Zero Server Storage: Your recordings are processed in-memory and discarded immediately after transcription. No audio files or transcripts are stored on any server.
  • Client-Side Key Privacy: Your secret API key is stored only inside your browser's private local storage. It is never logged or saved to any central database.
